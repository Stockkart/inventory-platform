# Plugins

Vertical and composition packages that extend the core app without bloating domain modules.

| Package                 | npm name                              | Role                                             |
| ----------------------- | ------------------------------------- | ------------------------------------------------ |
| [cafe](./cafe/)         | `@inventory-platform/plugin-cafe`     | Cafe vertical: menu, sell, ingredient stock      |
| [registry](./registry/) | `@inventory-platform/plugin-registry` | Loads verticals, composes nav + dashboard routes |

See [VERTICAL_PLUGIN_ARCHITECTURE.html](../../docs_stockkart/VERTICAL_PLUGIN_ARCHITECTURE.html) and [CAFE_VERTICAL_ARCHITECTURE.html](../../docs_stockkart/CAFE_VERTICAL_ARCHITECTURE.html).
